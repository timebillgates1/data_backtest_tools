# 가격 데이터 수집·분석·검증 도구 (Python)

주식·코인 가격 데이터를 자동으로 내려받아 규칙 기반 전략의 과거 성과를 계산하고,
그 결과가 **우연인지 검증**하는 도구입니다. 투자 조언이나 수익 보장이 아니라, 분석 도구 개발 샘플입니다.

## 포함 파일
- `breakout_backtest.ipynb` : 국내 주식 일봉 분석 (테마 필터, 파라미터 조합 비교, 워크포워드 검증)
- `coin_timeframe_backtest.ipynb` : 코인 1시간/4시간/일봉 비교 (비용 3배, 기간 분할, 종목 제거)

## 기능
- 야후 파이낸스(yfinance), 거래소 시세(ccxt)로 데이터 자동 수집
- 수수료·슬리피지, 손절, 분할 익절, 트레일링 스탑을 반영한 매매 시뮬레이션
- 계좌 단위 시뮬레이션 (1회 손실 한도 기준 비중 조절, 동시 보유 종목 수 제한)
- 견고성 검증: 파라미터 27조합, 비용 2배/3배, 기간 분할, 종목 절반 랜덤 제거, 워크포워드
- 결과를 표로 정리 (연평균, 최대 낙폭, 매매 횟수, 기간별 성과)

## 사용 방법
1. Google Colab(colab.research.google.com)에서 노트북 업로드
2. 런타임 → 모두 실행
3. 결과 표 확인

## 사용 기술
Python, pandas, numpy, yfinance, ccxt

## 한계 (결과 해석 시 주의)
- 현재 거래되는 종목만 포함해 **생존 편향**이 있습니다.
- 일봉/시간봉 근사이며 호가·체결 속도, 세금은 반영하지 않았습니다.
- 과거 성과는 미래를 보장하지 않으며, 투자 권유가 아닙니다.
